# 유성클리닝 현장 출력 프로그램

세탁공장 현장에서 날짜와 코스를 고른 뒤, 배송·세탁·마감용 문서를 바로 인쇄하는 웹 프로그램이다.
원본 데이터는 구글 시트 「세탁공장-현황지-거래처」이고, 시트에 붙은 Apps Script가 데이터 API 역할을 한다.

- 화면 주소: https://partybok-crypto.github.io/print_status_sheet/
- 배포: `master`에 push하면 GitHub Pages로 자동 배포된다(`.github/workflows/pages.yml`).
  - 배포 때 `index.html`·`admin.html`의 `__BUILD_ID__`를 커밋 번호로 바꾸고 `version.json`을 만든다. 열어 둔 창은 5분마다 이것을 비교해, 옛 버전이면 1분 넘게 조작이 없을 때 자동으로 새로고침한다. 인쇄 버튼을 누른 순간에 옛 버전이면 새로고침하고 다시 누르라고 안내한다.
  - 현장 화면은 불러온 지 3분 넘은 데이터로는 인쇄하지 않는다(인쇄 버튼을 누르면 먼저 다시 불러온다). 조작이 없을 때도 3분마다 다시 불러온다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 현장 출력 화면(기본 진입). 날짜 → 코스 → 문서 → 인쇄 |
| `admin.html` | 관리·편집 화면. 배송순서 변경, 업체 추가·제외, 기사·코스 수정, 출력 기록 |
| `wash-core.js` | 세탁공정 배정 계산(수량 산정, 세탁기 4대 회차 배정, 검증). 화면과 분리된 순수 모듈 |
| `Code.gs` | Apps Script 데이터 API(`doGet`/`doPost`). **읽기 전용**이라 시트에 절대 쓰지 않는다 |
| `당일기사.gs` | 「세탁물 현황」 당일 배송기사 자동 기록. 시트에 쓰는 유일한 스크립트 |
| `tools/nametag_helper.ps1` | 이름표 인쇄 도우미. 현장 PC에서 TSC TTP-247로 직접 출력한다(127.0.0.1:9123) |
| `tests/wash-core.test.js` | `wash-core.js` 테스트. `node tests/wash-core.test.js`(외부 패키지 없음) |
| `reference/` | 세탁공정·합세탁 체크표 출력 견본 |

화면에서 바꾼 값(배송순서, 제외 업체, 기사·코스 수정 등)은 브라우저 `localStorage`에 날짜별로만 저장된다. 원본 시트에는 반영되지 않는다.

## 출력 문서

자주 쓰는 출력

1. 현황지 + 주소지: 배송기사용, 2개 문서를 이어서 출력
2. 세탁공정: 세탁팀용 참고표, 세탁기 배정 포함
3. 합세탁 체크표: 마감자용
4. 마감자용 수량표 + 전체주소지: 세탁 마감용, 2개 문서를 이어서 출력
5. 출력 후 라벨코스 변경내역
6. 이름표 출력: 업체번호를 넣으면 라벨 프린터로 1장 출력

기타 출력: 주소지만, 현황지만, 마감자용 수량표만, 전체주소지만

## 원본 시트(읽는 위치)

- **세탁물 현황** (4행부터 업체 데이터)
  - A~F: 요일별 배송순서(코스코드). 1행 머리글에 "OO요일"이 들어 있다
  - H: 구역, I: 당일 기사(자동 기록), J: 합세탁, K: 업체번호, L: 약칭, M: 업종
  - N: 포대 배송, O: 수건 배송, P: 수거량, Q: 사이즈
  - T~Z: 월~일 배송 여부(값이 1이면 그 요일 배송)
  - AD: 주소, AE: 수거방식, AF: 배송 코멘트, AG: 거래처 번호
- **거래처**: A 업체코드, X~AC 요일별 배송코스(화~일), AD~AI 요일별 배송기사(화~일)
  - 기사 이름은 이 열을 기준으로 정한다
- **업체별 수거량**: 세탁공정 수량 이력
- 외부 시트: 「세탁공장-일정표」(세탁공정 작성자, 현황지 상단 오늘 마감 담당), 현장입력 시트(기사 앱·배송입력 앱 실수량)
  - 마감 담당: `주차별 쉬프트` 탭 위쪽 30행(이번 주 일정표)에서 현황지 날짜 블록의 포지션 "마감"인 사람 → 「근무자정보」 탭 E열(근무자명)·M열(핸드폰번호)로 전화번호. 30분 캐시(못 찾으면 10분)

월요일은 휴무라 월요일 배송 열과 배정표가 없다.

## Apps Script 배포

- clasp 연결이 없어 시트의 확장 프로그램 → Apps Script 편집기에서 직접 고친다.
- `Code.gs`를 바꾼 뒤에는 배포 → 배포 관리 → 기존 배포 수정 → **새 버전**으로 다시 배포해야 화면(`/exec`)에 반영된다.
  - 반영됐는지는 실제 `/exec` 응답으로 확인한다.
- `당일기사.gs`는 웹 앱과 상관없이 트리거로 돈다. 저장만 하면 바로 적용된다.

## 당일 배송기사 자동 기록 (`당일기사.gs`)

「세탁물 현황」 탭의 세 칸에 쓴다.

- I4:I(마지막 행): 오늘 배송 나가는 업체 줄에 기사 이름을 적는다(전화번호 제외). 나머지 줄과 월요일은 비운다.
- L2: 오늘 날짜
- N1: 오늘 요일

당일 배송 판정과 기사 이름은 `Code.gs`의 `buildDayData_`와 같은 규칙을 쓴다. 「거래처」 기사 칸이 `---`(미배정)이면 비운다.

트리거(편집기에서 `setupTodayDriverTrigger`를 한 번 실행하면 둘 다 다시 걸린다)

- `updateTodayDrivers`: 매일 0시대(Asia/Seoul)에 실행
- `onEditTodayDrivers`: 아래 칸을 고치면 바로 다시 기록
  - 세탁물 현황: A~F, K, T~Z
  - 거래처: A, X~AI
